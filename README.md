# Movie Library — Личная кинотека

**Автор:** Чечевишникова Таисия
**Дата:** май 2026г.

## Описание

Приложение для управления личной коллекцией фильмов с графическим интерфейсом. Позволяет добавлять, удалять, фильтровать и просматривать фильмы с сохранением данных в JSON‑формате.

## Функциональность

* **Добавление фильмов:** ввод названия, жанра, года выпуска (1900–2026) и рейтинга (0–10).
* **Валидация ввода:** автоматическая проверка корректности данных.
* **Фильтрация:**
  * по жанру (частичное совпадение, регистронезависимо);
  * по году выпуска (точный год).
* **Удаление фильмов:** выбор из таблицы и удаление с подтверждением (поиск по содержимому, а не по индексу).
* **Сохранение данных:** автоматическое сохранение в файл `movies.json`.
* **Загрузка данных:** при запуске приложение загружает сохранённые фильмы.
* **Удобный интерфейс:** таблица с прокруткой, информативные сообщения об ошибках и успехах.

## Пример использования

### Шаг 1. Добавление фильма

1. Запустите приложение командой `python main.py` (или `python3 main.py`).
2. Заполните поля в верхней части окна:
   * **Название:** «Человек-паук»;
   * **Жанр:** «боевик»;
   * **Год:** 2020;
   * **Рейтинг:** 9.
3. Нажмите кнопку **«Добавить фильм»**.
4. Убедитесь, что фильм появился в таблице ниже.
5. Закройте приложение и откройте снова — фильм сохранится в таблице (загрузится из `movies.json`).

### Шаг 2. Фильтрация фильмов

1. В поле **«Фильтр по жанру»** введите «Бое» и нажмите **«Применить»**. В таблице останутся только фильмы, в жанре которых есть подстрока «бое» (например, «Боевик»).
2. В поле **«Фильтр по году»** введите 2020 и нажмите **«Применить»**. В таблице останутся фильмы 2020 года.
3. Чтобы сбросить фильтры, нажмите кнопку **«Сбросить фильтры»** — отобразится полный список фильмов.

### Шаг 3. Удаление фильма

1. Выберите любой фильм в таблице (кликните на строку).
2. Нажмите кнопку **«Удалить выбранный фильм»**.
3. Подтвердите удаление во всплывающем окне.
4. Убедитесь, что фильм исчез из таблицы и больше не появится после перезапуска приложения.

## Тестирование
* Добавление фильма с корректными данными — фильм появляется в таблице и сохраняется в `movies.json`.
* Фильтрация по существующим жанру/году — отображаются только подходящие фильмы.
* Удаление выбранного фильма — запись исчезает из таблицы и данных.
* Перезапуск приложения — все фильмы загружаются из `movies.json`.
